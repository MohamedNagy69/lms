# 📚 LMS محدّث — Dr. Nagi El-Ghieti Platform

**ترقية شاملة** من منصة تعليمية بسيطة إلى **نظام إدارة تعليم متكامل (LMS)** بـ **Django 5.2 + MongoDB**.

## ✨ المميزات الرئيسية

### 🔒 نظام أمان متقدم (الأقوى في السوق)
- **العلامة المائية المتحركة:** اسم الطالب + رقم الهاتف يتحركان على الفيديو
- **منع تصوير الشاشة (Anti-Screenshot):** تعتيم فوري عند الضغط على PrintScreen
- **كشف برامج التسجيل:** منع OBS، Camtasia، وأدوات المطورين (F12)
- **نظام الإنذارات (Strike System):** تحذيرات صوتية + حظر ساعة واحدة عند التكرار
- **جلسة واحدة فقط:** منع فتح حساب واحد من أجهزة متعددة
- **حماية Google Drive + YouTube:** نفس معايير الأمان على جميع مصادر الفيديو

### 🎓 نظام امتحانات ذكي
- تايمر دقيق + كشف محاولات الغش الفورية
- تصحيح آلي فوري للدرجات
- عرض الإجابات النموذجية والضعف للطالب
- نسب نجاح قابلة للتخصيص

### 📊 إدارة متقدمة
- توليد أكواد تفعيل مع تاريخ صلاحية
- استرجاع كلمات المرور عبر واتساب مباشر
- **بوابة أولياء الأمور:** متابعة الحضور + الدرجات + التقدم
- تقارير شاملة + تصدير Excel

### 🚀 الأداء
- **Server-Side Rendering:** HTML جاهز من السيرفر (بدون Hydration)
- **Zero JavaScript Bloat:** Vanilla JS حديثة بدون frameworks ثقيلة
- **WhiteNoise + Brotli:** ضغط عالي وتحميل سريع
- **Query Optimization:** select_related + prefetch_related لمنع N+1

### 🌍 التصميم
- **عربي أصيل (RTL Full):** خطوط Cairo + تصميم محترف
- **وضع ليلي حديث:** تدرجات داكنة + ألوان تفاعلية
- **Responsive 100%:** موبايل + تابلت + ديسكتوب
